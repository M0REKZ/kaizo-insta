Kaizo-Insta is a DDNet-Insta modification with extra features like weapons, mines, laser-jump, turrets, vehicles and water!

For build instructions visit the [ddnet repo](https://github.com/ddnet/ddnet).

---

Servers:
* Instagib/Vanilla PVP: 178.156.153.34:8304
* DDrace: 178.156.153.34:8305
* Block: 178.156.153.34:8306
